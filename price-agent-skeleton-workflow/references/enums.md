# 枚举与魔法值对照表

本文件只解释各 MCP 入参与返回字段的取值含义，便于自检调用是否正确，不提供业务事实。
实际取值以本轮 MCP 返回为准；本表与返回结构冲突时按返回结构处理，并说明差异。

## 提示词版本状态 `version_status`

| 值 | 含义 | 可否初始化/修改 | 可否直接发布 |
|---:|---|---|---|
| 1 | 草稿 | 可以 | 可以（经用户确认） |
| 2 | 线上 | 不可以 | 已在线上 |
| 3 | 归档 | 可以 | 不可直接发布 |


## 验证任务状态 `task_status`

| 值 | 含义 | 结果是否可读 |
|---:|---|---|
| 1 | 待执行 | 不能 |
| 2 | 执行中 | 不能 |
| 3 | 成功 | 可以 |
| 4 | 失败 | 不能 |
| 5 | 取消 | 不能 |

只有 `task_status=3` 时才可读取验证结果。

## Badcase 过滤 `label_filter`

| 值 | 含义 |
|---:|---|
| 0 | 全部 |
| 1 | 同款 |
| 2 | 非同款 |
| 3 | Badcase（人工标签与模型结论不一致） |

Badcase 分析流程固定使用 `label_filter=3`。

## 提示词来源 `source_type`

| 值 | 含义 |
|---:|---|
| 1 | 系统生成 |
| 2 | 模型优化 |
| 3 | 系统初始化 |

本 Skill 产生的所有写入固定使用 `source_type=2`。

## 通用返回码 `base_resp.resp_code`

| 值 | 含义 | 处理 |
|---:|---|---|
| 1 | 成功 | 继续读取 `data` |
| 其他 | 失败 | 按 [SKILL.md](../SKILL.md) 的失败与重试规则处理，并向用户说明 `resp_desc` |

`resp_code=1` 只表示调用成功，不表示 `data` 内容完整。各流程仍需按自身要求校验关键字段非空。

## 线上版本查询开关 `query_online`

| 值 | 含义 |
|---:|---|
| false | 按 `prompt_version_id` 或 `version_name` 精确查询 |
| true | 查询当前线上版本，忽略 ID 与名称 |

本 Skill 的初始化和修改流程固定传 `false`，禁止以线上版本为基础。
