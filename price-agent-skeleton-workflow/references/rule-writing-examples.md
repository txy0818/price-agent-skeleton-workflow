# 规则表达示例

仅参考表达方式，不把示例中的业务事实写入新提示词。类目、优先级、阈值、映射和例外
必须来自本轮 MCP 查询。

## 适用范围

```markdown
### 版本

- **适用类目**：仅在规则查询返回的鞋类范围内生效。
- **不适用时**：不抽取、不匹配，也不输出到 `extracted`。
```

## 来源优先级

```markdown
- **优先级**：商品属性 > 商品标题 > 主图。
- 高优先级来源已有明确信息时，不使用低优先级来源覆盖。
- 多个来源信息一致时，`source` 使用 `+` 连接。
```

## 例外与否决关系

```markdown
- 先执行通用规则，再执行当前比价项的明确例外。
- 只有规则查询明确规定为否决项时，才允许该项单独判定 `different`。
- 信息缺失不自动等于不匹配；按当前规则处理缺失值。
```

## 映射

```markdown
- 只有本轮映射查询返回为同组的值才允许等价。
- 不同映射组之间不得根据语义相近自行合并。
- 未查询到的品牌、材质或别名不得凭常识补充。
```
