# Badcase 归因与处理规范

三个 Badcase workflow 必须完整读取并执行本文件。每条 Badcase 只选择一个一级归因；可以在依据中
记录次要现象，但不得输出多个并列类型。只有“提示词规则缺陷”允许生成候选提示词、调用 `[S3]`
并展示 Diff。

## 统一证据链

按以下顺序建立证据，不得跳步或用模型输出自证：

1. **客观商品事实**：先核对左右商品快照中的标题、商详、属性和主图；缺失项保持缺失。
2. **模型实际处理**：核对 `analysis_process` 中各比价项的 `left/right.value`、`source`、`match`；
   单条流程的 `raw_llm_response` 只作补充，不替代结构化证据，整任务流程不使用它。
3. **标签与结论**：核对 `human_label`、`model_label`、顶层理由和逐项结论是否一致。
4. **可信业务约束**：核对本轮真实类目规则和必要映射，并说明验证时规则可能与当前规则不同。
5. **任务提示词**：逐字核对任务实际使用的 `prompt_content`，定位缺失、错误、歧义、冲突或作用域
   问题；不得查询其他提示词替换任务基础版本。

## 八类一级归因

| 类型 | 充分判定条件 | 分析处理 | 是否修改提示词 |
|---|---|---|---|
| 提示词规则缺陷 | 商品证据支持人工标签，可信业务规则明确，且错误因果链可定位到提示词缺少规则、规则错误、歧义、冲突，或适用范围/优先级/信息源约束不完整 | 说明缺陷位置、影响范围和回归样本；生成完整候选正文并执行 `[S3]` | 是 |
| 模型未遵循规则 | 商品事实和模型抽取均正确，提示词已明确规定结论，但模型最终 `match`、标签或理由与明确规则相反 | 引用提示词原规则与相反输出；记录执行稳定性问题并回归观察 | 否 |
| 模型抽取或推理异常 | 快照证据充分，但模型漏抽、错抽、来源判断错误，或抽取正确后发生无法由提示词规则解释的推理跳步 | 指出具体比价项、期望抽取/推理与实际差异；交给模型能力或推理链优化 | 否 |
| 业务规则问题 | 提示词忠实表达可信业务规则，模型也按规则执行，但规则本身不合理、过期或与目标口径冲突 | 标明规则来源和影响类目；提交规则负责人修订，修订后重跑验证 | 否 |
| 疑似人工标签错误 | 商品客观证据不支持人工标签，且模型结论与可信规则及事实一致 | 给出反证，提交人工复标；复标前不改提示词 | 否 |
| 映射或样本数据问题 | 已确认关系映射错误/缺失，或验证集标题、属性、图片、商品快照存在错误、错位或过期，并直接导致结论 | 指明具体映射或字段及修复方；修复数据后重跑 | 否 |
| 解析或系统链路异常 | 已确认原始模型结果、结构化解析、标签转换、落库或接口出参之间不一致，或字段错位/截断 | 指明异常发生层级，交给解析、存储或接口链路排查 | 否 |
| 证据不足 | 缺少足以确认客观事实、可信规则、模型过程或因果链的必要证据，无法可靠落入以上任一类 | 明确列出缺失证据和补证方式；补证前停止修改 | 否 |

## 冲突消解顺序

当多个现象同时出现时，按根因证据而非表面症状选择唯一一级类型：

1. 先判断证据是否足够；无法建立客观事实或因果链时归“证据不足”。
2. 已确认跨层结果不一致时优先归“解析或系统链路异常”，不得把解析错误归给模型或提示词。
3. 已确认上游映射或样本错误直接造成结论时归“映射或样本数据问题”。
4. 客观证据反驳人工标签，且其他链路一致时归“疑似人工标签错误”。
5. 提示词忠实表达规则而规则本身有问题时归“业务规则问题”。
6. 可信规则正确但提示词缺失、错误、歧义、冲突或作用域不完整时归“提示词规则缺陷”。
7. 提示词明确且抽取正确、模型仍给出相反结论时归“模型未遵循规则”。
8. 输入证据充分但模型漏抽、错抽或发生其他推理跳步时归“模型抽取或推理异常”。

仅凭 `is_correct=0`、人工标签、模型理由或当前规则与提示词不一致中的任意单项，都不能单独证明
提示词缺陷。规则完全缺失可以构成提示词缺陷，但必须指出可信规则来源、应出现的位置及与错误结果
之间的因果关系。验证时规则快照不可用且结论依赖“当前规则已经变化”这一假设时，归“证据不足”，
先用当前提示词和规则重跑验证。

`analysis_process` 为空本身不等于数据问题或链路异常：确认样本/快照错误时归“映射或样本数据问题”；
确认原始结果到解析、标签转换、落库或接口出参之间丢失/错位时归“解析或系统链路异常”；无法确认
缺失层级时归“证据不足”。

## 分析结果要求

每条结果必须包含：唯一一级类型、客观证据、模型实际处理、规则/映射依据、提示词对照、根因判断、
处理责任方和回归方式。整任务先逐条归因，再按八类统计；不得先看汇总比例反推单条根因。只有归为
“提示词规则缺陷”的样本进入候选修改合并，其他七类必须明确排除在 Diff 之外。
